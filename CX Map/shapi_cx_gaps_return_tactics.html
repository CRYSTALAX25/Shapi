01 WhatsApp signup — bypass email confirm Candidate + Company P1 critical
Problem: Email confirm wall kills activation, especially in MENA where WhatsApp is primary.

What to build
On /signup add "Sign up with WhatsApp" button. Generate a 6-digit OTP, send via Twilio WhatsApp. On confirm, create Supabase user with phone_confirmed=true, skip email confirm, redirect to CV builder (candidate) or onboarding (company).

Claude Code tasks
  • Add whatsapp_phone column to profiles table (Supabase migration)
  • New API route /api/auth/whatsapp-otp — send OTP via Twilio, store in Redis with 10min TTL
  • New API route /api/auth/whatsapp-verify — verify OTP, upsert Supabase user, return session
  • Update /signup UI — add WhatsApp toggle above email form
  • Pair WhatsApp at this step (not at dashboard) — saves the pairing step later
02 CV builder progress bar + estimated time Candidate P1 critical
Problem: No progress indicator = users feel trapped = 40-60% drop-off (2024 SaaS data).

What to build
Add a step counter to CV builder state. Show "Step 3 of 8 · ~4 min left" fixed at top of interview UI. Add subtle progress bar (filled left-to-right). Show "Skip to dashboard — finish later" link from step 2 onward.

Claude Code tasks
  • Track interview_step and total_steps in CV builder state
  • Add sticky header component with step pill + progress bar
  • Add "Save & continue later" route — stores partial cv_draft in Supabase, redirects to dashboard
  • Dashboard shows "Finish your CV" card if cv_draft exists and completion_pct < 80
03 Workforce Snapshot as step 1 in company onboarding Company P1 critical
Problem: Snapshot is currently buried below fold on dashboard. It is the wedge — it must be the first experience.

What to build
After /company/onboarding completes, redirect to a full-screen Snapshot flow (5 inputs, ~2 min), not to dashboard. On Snapshot completion, redirect to dashboard with results pre-loaded. Store snapshot_count on company profile — hide the nudge on dashboard once >0.

Claude Code tasks
  • Update /company/onboarding final step redirect: /company/workforce-snapshot?first=true
  • Add ?first=true flag to Snapshot page — hides back button, shows "See your results" CTA only
  • On Snapshot submit, store snapshot_count++ and redirect to /company/dashboard?snapshot=done
  • Dashboard: if snapshot=done in query, show inline upsell toast for Growth ($799) 7-day trial
04 Reference automated nudge sequence Candidate P1 critical
Problem: Referee completion is the verification flywheel — currently stalls because there's no automated chasing.

What to build
When reference request is sent, start a 3-step drip: Day 1 email to referee, Day 3 WhatsApp to candidate ("Chase {Name}?"), Day 7 email reminder to referee with new link. Auto-expire the token at Day 14 and prompt candidate to re-send.

Claude Code tasks
  • Add ref_status enum: sent | reminded | completed | expired to reference tokens table
  • Add cron job /api/cron/references — runs daily, checks sent_at age, fires Day3/Day7 messages
  • WhatsApp template: "Your reference from [Name] is outstanding. Tap to send a reminder →"
  • On ref completion: trigger upsell to Active ($29) via WhatsApp — "You now have {N} verified refs. Companies with 3+ get priority shortlisting."
05 Post-[DONE] upsell: blurred CV preview Candidate P2 high
Problem: Kit/Pro one-time payment is asked cold, with no preview of what's behind the gate.

What to build
Immediately after [DONE] token fires in CV builder, render a blurred PDF preview overlay with a lock icon. Two CTAs: "Unlock Kit · $25" and "Unlock Pro · $59" with a 3-bullet feature diff. If dismissed, add a persistent "Your CV is ready" card to dashboard with same blur.

Claude Code tasks
  • Generate a partial PDF preview (first page only) server-side after [DONE], stored in Supabase storage
  • CV builder: on [DONE] detection, replace interview UI with CVPreviewGate component
  • CVPreviewGate: blurred <img> + lock overlay + Kit/Pro CTA buttons linking to /pay?tier=kit or /pay?tier=pro
  • Dashboard: if cv_tier = null and completion_pct > 80, show persistent CV upsell card
06 Active Hiring 7-day trial trigger at role post Company P2 high
Problem: $499/mo is a cold ask. Highest intent moment is right after posting a role — trial must be offered there.

What to build
After /company/roles/new saves the role, show a modal: "Your role is live. Want Shapi to shortlist verified candidates daily? 7-day free trial — no card required." If accepted, set trial_active=true, trial_expires=now+7days, enable Active Hiring features. On day 6, send WhatsApp: "Your trial ends tomorrow — {N} candidates shortlisted this week."

Claude Code tasks
  • Add trial_active, trial_product, trial_expires to company profiles table
  • Post-role-save: render TrialOfferModal component (not a redirect)
  • Trial activation API: POST /api/company/trial/start — sets trial fields, queues Day6 WhatsApp via cron
  • Feature flag check: hasActiveHiring(company) = subscribed OR trial_active AND trial_expires > now
  • Trial expiry cron: downgrade gracefully, send "upgrade or lose access" WhatsApp
07 Monthly ROI digest — company retention Company P2 high
Problem: No quantified value recap = CFO cuts the tool at next audit. B2B SaaS CFOs cut any tool not used daily (2026 data).

What to build
On the 25th of each month, generate a 1-page ROI digest per company: candidates shortlisted, interviews scheduled, hours saved (shortlisting time estimate), roles filled. Send via WhatsApp (summary) + email (full). Include annual plan offer (2 months free = saves 16%) at the bottom.

Claude Code tasks
  • New cron /api/cron/monthly-roi — runs on 25th, queries pipeline activity per company
  • ROI calculation: hours_saved = shortlists_sent × 1.5 (recruiter hours per manual shortlist)
  • WhatsApp template: "📊 May recap: {N} candidates reviewed, {M} interviews, ~{H}hrs saved. [Full report →]"
  • Email: render ROI report page as React PDF or HTML email via Resend
  • Inline CTA: "Switch to annual — pay {10×monthly}, get 12 months." with Stripe annual plan link
08 Payment failure dunning via WhatsApp Candidate + Company P2 high
Problem: Up to 40% of SaaS churn is involuntary (failed payments). No dunning = pure preventable loss.

What to build
Stripe webhook on invoice.payment_failed: send WhatsApp within 2hrs with update-card link. Day 3 follow-up. Day 7 final warning — downgrade gracefully (don't delete data). Stripe's smart retry handles card attempts; Shapi handles communication.

Claude Code tasks
  • In /api/stripe/webhook: add handler for invoice.payment_failed event
  • Generate Stripe Customer Portal session URL (one-click card update)
  • Send WhatsApp: "Payment issue — tap to update your card in 30 seconds: [link]. Access stays live until [date+7]."
  • Schedule Day3/Day7 follow-ups via cron queue (store dunning_step on subscription record)
  • On Day7 no payment: set subscription_status=grace_expired, hide paid features, preserve all data
09 Feedback loop — candidate ghosting prevention Candidate + Company P3 medium
Problem: 44% of candidates cite ghosting as top frustration. If Shapi enables ghosting, it damages trust on both sides.

What to build
After interview is scheduled, set a 5-day feedback timer. If company hasn't logged feedback in /company/pipeline, send WhatsApp nudge. If still nothing after 10 days, auto-send a templated "thanks but not progressing" message to candidate on company's behalf (with opt-out). Track "feedback rate" as a company health score visible in /admin.

Claude Code tasks
  • Add feedback_deadline to pipeline stage records (interview_date + 5 days)
  • Cron: check overdue feedback daily, send WhatsApp to hiring manager
  • Auto-message opt-in: company settings toggle "Allow Shapi to send closure messages on my behalf"
  • Admin panel: add "Feedback rate %" column to company table — flag <50% for outreach
10 3 free role previews (blurred) for unsubscribed candidates Candidate P3 medium
Problem: /roles is fully gated — candidates see zero value before paying. Hard gate with no taste converts poorly.

What to build
Show 3 role cards on /roles with salary and company name visible, description blurred. "See full role" triggers upgrade prompt to Roles Board ($19/mo). Rotate the 3 previews weekly so return visitors see fresh content (reason to check back).

Claude Code tasks
  • Roles query: if !hasRolesBoard(user), return top 3 roles with description_preview only
  • Role card: blur(4px) on description, lock icon, "Unlock all roles · $19/mo" CTA
  • Weekly rotation: add preview_featured=true flag to roles table, cron rotates on Monday
  • Track roles_preview_click event in analytics — use as conversion signal
